# 🌱 AgroVisionTI

Sistema desktop para gerenciamento de ativos de TI desenvolvido em **Java**, utilizando **Swing**, **JDBC** e **MySQL**.

O objetivo do projeto é centralizar o controle dos equipamentos de TI da empresa, permitindo o gerenciamento de notebooks, desktops, monitores, impressoras e demais ativos de forma simples e organizada.
